QR AJN

REST API v1

Business and Enterprise API keys use Authorization: Bearer qrajn_.... Keys are scoped and hashed at rest.

Read QR codes

GET /api/v1/public?action=qrs
Authorization: Bearer qrajn_...

Read profiles

GET /api/v1/public?action=profiles
Authorization: Bearer qrajn_...

Analytics

GET /api/v1/public?action=analytics
Authorization: Bearer qrajn_...

Webhooks

Configured webhooks receive JSON with x-qrajn-event and x-qrajn-signature. Verify the HMAC signature with the one-time signing secret generated when the webhook is created.

Rate limits

API usage is enforced by the account plan. Business includes a finite monthly allowance; Enterprise can be configured as unlimited.
